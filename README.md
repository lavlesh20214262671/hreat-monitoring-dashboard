# 🚀 Real-Time Threat Monitoring Dashboard

A full-stack system monitoring and threat intelligence dashboard that simulates real-time alerts, system metrics, and security insights.

---

## 🔧 Tech Stack

* **Backend:** Python (FastAPI)
* **Frontend:** HTML, CSS, JavaScript
* **System Tools:** psutil (optional)
* **Architecture:** Modular (API + Logic + UI)

---

## ⚙️ Features

* 📊 Real-time system monitoring (CPU, memory, performance)
* 🚨 Threat detection and alert simulation
* 📡 REST APIs for metrics, alerts, and logs
* 🧠 Modular backend with separate threat engine logic
* 🌐 Interactive dashboard UI

---

## 📁 Project Structure

```
├── main.py               # API server
├── threat_engine.py      # Threat logic
├── models.py             # Data models
├── data_store.py         # Data handling
├── index.html            # Dashboard UI
├── requirements.txt
```

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
python main.py
```

Open:

```
http://localhost:8000
```
